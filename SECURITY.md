# Security Policy

## Supported Versions

The following versions are currently receiving security updates:

| Version | Supported          |
| ------- | ------------------ |
| 5.1.x   | :white_check_mark: |
| 5.0.x   | :white_check_mark: |
| 4.5.x   | :white_check_mark: |
| < 4.5   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability, please report it responsibly by opening a [GitHub Security Advisory](../../security/advisories/new) in this repository instead of a public issue.

You can expect the following process:

- **Acknowledgement** within 48 hours of your report.
- **Status updates** every 5–7 days while the issue is being investigated.
- If the vulnerability is **accepted**, a patch will be issued as soon as possible and you will be credited (unless you prefer anonymity).
- If the vulnerability is **declined**, a clear explanation will be provided.

Please include as much detail as possible in your report: steps to reproduce, affected versions, potential impact, and any suggested mitigations.
